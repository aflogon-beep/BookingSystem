# Ruta Reservas

Sistema de reservas y operaciones para empresas de tours guiados: web de reservas con pago online y panel interno (día, calendario, manifiesto con check-in, reservas, equipo, informes).

**Estado:** kit inicial. Empieza por [`docs/PRIMEROS-PASOS.md`](docs/PRIMEROS-PASOS.md).

| Documento | Para qué |
|---|---|
| `CLAUDE.md` | Contexto y reglas que Claude Code lee en cada sesión |
| `docs/PRD.md` | Qué hace el producto |
| `docs/ARCHITECTURE.md` | Modelo de datos y flujos críticos |
| `docs/ROADMAP.md` | Tareas por fases |
| `prototype/index.html` | Prototipo navegable de referencia (ábrelo en el navegador) |
| `.claude/skills/` | Skills del proyecto: dominio, Supabase, Stripe, diseño, tests, seguridad |
| `.claude/agents/revisor-codigo.md` | Agente revisor de código |

Stack: Next.js · TypeScript · Tailwind + shadcn/ui · Supabase · Stripe · Resend · Vercel.

Fotos del prototipo: Wikimedia Commons (autores y licencias en la web de reservas del prototipo).
